    One shared scene.

    The Android app and browser read the same synthetic component file. Height distinguishes blocks visually. Connections illustrate a teaching layout and do not specify physical wiring.

    Measured draw cost.

    Run a short camera sweep to measure Canvas draw-call wall time in this browser.

    This measures synchronous drawing code, not GPU completion, display FPS or a physical phone benchmark.

    Implementation and limits

    The Android implementation uses Kotlin and Jetpack Compose. This browser companion uses Canvas 2D with perspective projection. Faces use global back-to-front sorting, not a depth buffer. Pins remain visible as selection markers. No GPS, board connection or external model service is used.
