# Toolchain and dependency provenance

- Gradle 8.9 wrapper: generated by the official Gradle 8.9 distribution.
  Wrapper license: `licenses/Gradle-LICENSE.txt`.
  https://github.com/gradle/gradle/tree/v8.9.0
- Kotlin and Compose compiler plugin 2.0.21:
  https://github.com/JetBrains/kotlin/tree/v2.0.21
- Android Gradle Plugin 8.7.3 and SDK: installed from official Google repositories.
  SDK tools are not bundled with this repository.
  https://developer.android.com/build/releases/agp-8-7-0-release-notes
- AndroidX/Compose libraries are fetched from Google's Maven repository under their
  published package licenses. They are dependencies, not original project code.
  https://android.googlesource.com/platform/frameworks/support/
- JUnit 4.13.2 is a test dependency, not part of the application runtime.
  https://github.com/junit-team/junit4/tree/r4.13.2

The scene data, browser styling, projection implementation, repair harness, and
illustrative geometry are project-owned. No stock photographs, third-party 3D
meshes, fonts, or copied app artwork are included.
